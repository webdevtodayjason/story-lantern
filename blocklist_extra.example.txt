# Story Lantern — household blocklist (optional)

# Copy this file to  blocklist_extra.txt  next to safety.py and it is loaded at import
# time by the deterministic backstop. Every line here is a HARD decline on the child's
# request AND a BLOCK on any generated page: the lantern will not build a story from it
# and will never read it aloud.
#
# One entry per line:
#   plain text   -> matched as a whole word, case- and leetspeak-insensitive
#   /regex/      -> matched as a Python regular expression against the normalised text
#
# This file is deliberately shipped empty of terms. The built-in `hate` rule only covers
# the obvious constructions; a curated slur list belongs in a file a parent can read,
# edit and diff — not compiled into the product. Add yours here.
#
# Examples:
# voldemort
# /\bthe (?:red|blue) house on \w+ street\b/
